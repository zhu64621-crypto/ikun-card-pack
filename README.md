# ikun变装秀 · 3D 全息撕卡包

零依赖纯前端 3D 铝箔卡包拆封与全息集换式卡牌互动网页（HTML / CSS / 原生 JavaScript）。

- **在线体验（GitHub Pages）**：https://zhu64621-crypto.github.io/ikun-card-pack/

## 核心特性

- **96 顶点锯齿双向撕包与 24 切片 3D 卷边回弹**：支持沿虚线从左到右或从右到左平滑撕开铝箔封口，未撕过阈值时触发弹性回弹动画。
- **摇晃预知稀有度**：拆封前拖拽或轻晃卡包，封口会提前透出本包最高稀有度的对应微光与提示。
- **未拆封卡包小鸡互动音效**：鼠标滑过未拆封卡包上的小鸡徽章可触发清脆提示音与 Q 弹反馈动画。
- **三阶段 3D 环绕飞出过渡**：撕开卡包后，5 张卡片会从包内呈 3D 环绕弧线依次飞出并丝滑归位排列。
- **动作游戏重击翻牌**：点击翻开卡片时触发重击打击感、微震动画面反馈以及持续 `0.5s` 的菱形扩散波纹。
- **5 档分区全息反光材质**：区分 Common / Rare / Holo Rare / Ultra Rare / 逆闪异画（Secret Rare），随鼠标角度呈现激光与折射光影。
- **3D 放大检视自定义音效**：点击已翻开卡片进入 3D 聚光灯检视，并播放自定义检视音频。
- **暗房 / 白棚双主题与本地卡册存档**：内置全闪测试模式、右上角模式指示，以及基于 `localStorage` 的收集图鉴记录。

## 本地运行

项目所有核心资源已内联并在本地目录完整保留，无需安装构建工具：

1. 直接双击打开 `index.html`；或
2. 在项目根目录启动本地静态服务器（推荐）：

```bash
python -m http.server 8765
```

然后在浏览器访问 `http://localhost:8765/`。
